# Fox Stars Lab v2.1.0-fox.1 发布说明

> **发布基线**：`2.1.0-fox.1` ｜ **数据库迁移**：`001–039`  
> 本版本汇总了 2.0 架构重建、批次 A 稳定性修复（`2.0.0-fox.2`）与 M1–M5 体验/发现全面升级（`2.1.0-fox.1`），正式桌面端通过全套回归测试并完成原地升级验证。

---

## 一、从 2.0 到 2.1.0-fox.1 的核心变化

### 1. 界面收敛与单层 6 页签设置（M1–M2）

- **精简主界面与历史冗余入口**：移除 10 个已淘汰或不可达的历史独立页面与旧「按类型看」重复视图，主导航定型为 **今日 / 资料库 / 找方案 / 发现 / 收集 / 设置**。
- **合并重构单层设置页**：将原设置页与工具箱合并拆分为 6 个清晰模块（`账号与同步` / `AI 设置` / `自动整理` / `备份与导出` / `外部连接` / `外观与关于`），消除重复入口。
- **动态 Token 估算**：`card_handler.rs` 根据最近 50 次成功 `repo_card` 任务的实际消耗动态计算 `avgTokensPerCard`（样本不足 3 条时回退默认保守值），让「每天还能整理多少个」更贴近所选模型真实开销。
- **第二轮文案审读清零**：统一用户可感知术语（如工具 / 收藏 / 资料库 / 收集箱 / 交接单 / 中文说明 / 每天额度），明确花钱操作的事前说明与受限口径。

### 2. 发现工作台全面升级（M3）

- **三大工作模式**（[apps/desktop/src/pages/v2/discover.tsx](../../apps/desktop/src/pages/v2/discover.tsx)）：
  1. **热门趋势**：新增 5 路精选榜单（今日飙升 `trending_daily`、本周热门 `trending_weekly`、本周新锐 `rising_7d`、本月黑马 `rising_30d`、HN Show 热门 `hn_show` 仅限 GitHub 项目）；其中 GitHub Trending 采用线性无正则 HTML 解析并在失败/限流时以 Search API 高星榜自动兜底。
  2. **自由搜索**：支持关键词、时间窗口（7d / 30d / 90d / 180d / 不限）、排序（星数 / 最近更新）、语言筛选与常用预设词。
  3. **按场景补缺**：结合用户已有业务场景分布，补充近 90 天新锐仓库配额（每批至多预留 6 个新锐项目），避免长期只推荐老牌仓库。
- **数据层与令牌复用**：新增迁移 `039_discover_feeds.sql`（`discover_feed_items`、`discover_feed_runs`）及 3 个 Tauri 命令；通过 `auth::optional_github_token()` 在不触发额外钥匙串弹窗的前提下复用已连接令牌（仅向 `api.github.com` 发送，遇 401 自动无令牌降级重试）。

### 3. 通用化交互打磨（M4）

- **键盘与跨页连贯性**：列表新增 `↑` / `↓` 方向键切换（与 `J` / `K` 并行）；离开再回到「资料库」时自动恢复筛选条件、搜索词、选中项与滚动位置。
- **详情页效率提升**：缩减详情页头部装饰高度，优先展示核心用途；「确认（不再自动覆盖）」按钮语义更加直观；新增一键 **「加入当前方案」**，可直接把浏览中的工具加入「找方案」交接单草稿。
- **去个人化与预算透明度**：界面文案去除绑定特定个人或特定 AI 客户端的称呼（统一使用通用称呼与「AI 助手」，账号名称按连接态动态读取），并明确「找方案 AI 精选」独立于后台自动整理配额的消耗关系。

### 4. 批次 A 修复与底座加固（2.0.0-fox.2 合并基线）

- **交接单与会话连贯（卡 75）**：改选工具、更换格式、更新问题或更新本机能力后旧交接单立即失效并禁止误复制，生成失败支持重试，乱序请求不覆盖最新选择；带入问题只消费一次，保留跨页勾选草稿。
- **检索、搜索框与缓存一致性（卡 49c / 76 / 77）**：
  - 「找方案」与三种格式交接单完整带上项目维护状态提醒（活跃 / 疑似停更 / 已归档 / 未知），不掩盖用户主动选择；
  - 顶部命令面板支持普通关键词回车搜索、上下键选择、Esc 关闭并恢复焦点；
  - 「去设置 AI」入口直达 AI 设置页；GitHub 同步与 README 完成事件正确触发已打开详情的缓存刷新；
  - 加固发布脚本与预算读取门禁（`release_test.py` 覆盖 23 个故障与越界场景）。

## 三、升级与使用注意事项

1. **数据库向后兼容**：从 1.x 或 2.0.x 启动 `2.1.0-fox.1` 时，程序会自动按顺序执行缺失迁移并在升级前自动保存 `.pre-migration-<ts>.sqlite3` 备份文件。
2. **macOS 临时签名应用升级提示**：替换重新编译的本地 `.app` 后，系统钥匙串首次读取既有 GitHub 令牌或 AI 密钥时可能弹出授权提示，点「始终允许」即可恢复免密读取。
3. **跨平台构建说明**：Windows 与 Linux 构建规范沿用 Monorepo 配置；当前 `.github/workflows/release.yml` 仍保留历史产物命名脚本，跨平台发布流水线适配列入 [路线图 P3](../ROADMAP.md)。
