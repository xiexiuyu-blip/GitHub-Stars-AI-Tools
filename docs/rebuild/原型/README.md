## 这版定了什么（等 Fox 确认）

1. **导航收敛为 5 项**：今日 / 资料库 / 找方案 / 收集 / 发现，加底部设置。地图并进资料库的场景筛选；参考包并进找方案右侧的托盘；工具箱与连接并进设置。
2. **今日**只回答「先看哪几个」：今天值得先看 3 个（从还没看过的里，按 Fox 常做的事挑）+ 本周新收藏；统计卡片兼筛选，不放计数墙。
3. **资料库**：左边按**业务场景**筛（小红书、公众号·微信、抖音·短视频、海报·封面·设计、视频·字幕·语音、PPT·文档、写作·文案、调研·爬虫、数据分析、知识库·笔记、自动化·工作流、电商、SEO·增长），库里偏少的方向标「偏少」；右边详情先结论后原文，「我的状态」五档，「复制给 Codex」是页面唯一的主按钮。
4. **找方案**：一句话说想做什么，按意图拆词；只默认勾选「所有意图都对上了」的；对不上时直接说缺了哪个，并引到「发现」；勾选的进右侧参考包（Markdown / AGENTS.md / JSON），一键复制。
5. **收集**：粘贴即识别，每条标「新 / 已在你的 Stars / 已在收集箱 / 将被拦下」，加入后进收集箱。
6. **发现**：按场景缺口去 GitHub 找还没收藏的；榜单是次要页签。
7. **确认不做成待办队列**：AI 说明下面只有一行「说得对吗？对 / 不对，重新整理」。

## 哪些是真的，哪些是示意

真的：库里 492 个仓库和已有的 177 条中文说明；场景个数（按关键词粗分）；收集页的链接识别（照 App 里新写的规则，已收藏的对照真实库）；发现页的候选（2026-10-03 在 GitHub 上按场景搜到的真实项目，显示 GitHub 原文）。

示意：「AI 正在整理」（8 月以后收藏的 174 个全都没有中文说明，原型如实显示成整理中，正式版会自动补上）；搜索（原型按意图拆词，正式版换向量）；同步、保存到文件夹、设置里的开关。

## 重新生成

```bash
python3 extract.py <dev 库的副本.sqlite3>   # 从库里生成 data.json
python3 cand.py                              # 联网搜 GitHub 候选，生成 cand.json（未认证接口，约 1 分钟）
python3 build.py                             # 生成 fox-stars-lab-prototype-v1.html，并写一个本地测试外壳 test.html
```

改界面只改 `template.html`；改完跑 `build.py`。

## 做这版时发现的事

- 中文说明只覆盖 2026 年 6 月（106 个）、7 月（71 个）收藏的；8 月 117 个、9 月 56 个、10 月 1 个，**一条都没有**。
- 86 张真卡里至少 15 张字段类型不对（9 张 `how_to_try` 是数组，6 张 `capabilities` 不是列表），说明没有按 schema 校验；`capabilities` 常是长句而不是短语；`how_to_try` 多半写着「摘录中未提供安装步骤」，因为 README 只给了前 1800 字。
- 关键词搜索会被重复出现的词带偏（「做小红书封面」的前几条全是「小红书」而不是「封面」），按意图拆词能明显改善，但根本办法是向量。
