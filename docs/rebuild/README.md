# `docs/rebuild/` 目录说明

本目录包含 **2.0 架构重建阶段** 沉淀的设计与工程资产。为保证构建依赖与运维溯源完整，目录整体保留，其中**现行有效文件**与**历史归档文件**边界如下。

## 现行有效文件（Active）

| 路径 | 作用与约束 |
|---|---|
| [`spec/`](spec/) | 编译期内嵌规则与种子文件（`ai_card.schema.json`、`discover_queries.json`、`scenarios_seed.json`、`taxonomy_seed.json`），被 Rust 后端通过 `include_str!` 直接编入二进制，**禁止移动路径** |
| [`切库清单.md`](切库清单.md) | 现行正式版 **D2 原地升级固定流程**与每次正式库升级实录 |
| [`文案审读.md`](文案审读.md) | 应用内统一中文用词表与多轮文案审读台账 |
| [`微信联动接入.md`](微信联动接入.md) | 外部工具通过本地 HTTP API `POST /v1/capture` 投递链接的接入说明 |
