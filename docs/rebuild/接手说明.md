## 1. 安全边界（硬规则）

1. 不读、不改正式数据目录，除非 Fox **明确同意切换正式库**。
2. 不切换正式 bundle id，不打 tag，不开 PR，除非 Fox 明确要求。
3. `repositories` / `repo_ai_documents` / `repo_tags` / `annotations` 现有列不改名、不删除（web-search `stars` 在直接读）。
4. 密钥只走 Keychain。服务名：正式 `fox-stars-lab`，开发 `fox-stars-lab-dev`。不要打印、不要写入日志/进度/提交。
5. 本地 API 默认关；开启后只听 `127.0.0.1:39217`，除 `GET /v1/health` 外都要令牌，带 `Origin` 的请求一律拒绝。令牌存在 0600 权限的 `fox-stars-lab.local-api.json` 里，不要打印。
6. 启动开发版用：

```bash
cd /Users/fox/WorkSpace/_external_tools/fox-stars-lab
COREPACK_HOME="$PWD/.corepack" pnpm dev:desktop
```

不要用 `pnpm tauri dev`（那是正式身份，debug 会被拒绝）。

7. 每次动系统级路径前，确认本机是 Fox 的机器，且正式版 App 没在跑。本机 `/Applications` 里装着正式版 `Fox Stars Lab`，**不要启动它**。
8. 直接读 dev 库时，SQLite 只读模式在 WAL 下可能报 `unable to open database file`（缺 `-shm` 辅助文件）。要分析数据，先 `sqlite3 <库> ".backup '<副本>'"` 拷一份再查，别为此改库。
