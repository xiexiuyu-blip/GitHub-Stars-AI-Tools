## 明早先看这个

开发版还没替你打开窗口。要看结果，先确认正式版 Fox Stars Lab 没在运行，然后在仓库目录执行：

```bash
COREPACK_HOME="$PWD/.corepack" pnpm dev:desktop
```

不要用 `pnpm tauri dev`。那条仍是正式身份，debug 构建会被启动检查直接退出。

打开后左侧应是 2.0 的 9 项。能用的是「今日」「资料库」「收集」。地图、找方案、参考包、工具箱会说明还没做完。发现与榜单、设置仍是上一版页面。

第一次启动会在 dev 目录里自动备份，然后把副本从 018 迁到 029。正式目录不会被打开。
