# 界面文字审读（站在 Fox 的角度）

2026-10-05：Fox 说「现在很多文字描述还不是很合理」。总控让一个只读审读员，以 Fox（做品牌营销 / 新媒体运营的非开发者）的身份，读了真实数据下渲染出来的全部页面和 `apps/desktop/src` 里的全部中文文案。下面是审读结果，加上总控的决定。**改文案的任务卡（31 / 32）以这份文件为准。**

路径相对 `apps/desktop/src/`；`R:` 开头的在 `apps/desktop/src-tauri/src/`。

## 总控的决定（审读员留给 Fox 的三个问题，Fox 说「你来定」）

1. **旧功能入口先藏起来，不删代码**：⚡ 菜单的「全局搜索」改成「搜工具」直接进「资料库」搜索；🔔 里去掉「仪表盘」；右上角头像点了去「设置」；⚡ 里的「增量 AI 解析」「生成标签网络」去掉（只留一项「给没有说明的收藏写中文说明」）；设置页去掉「标签网络」那一行、藏起「向量」页签（代码留着）。Gist 备份保留，但改成讲清楚是「上传到你的 GitHub 私密 Gist」。旧页面文件（`pages/dashboard|repositories|rankings|tag-network|ai-search|profile.tsx`）**不动**。
2. **金额先不写人民币**：服务商单价我们读不到。确认框和横幅里先用「预计整理 N 个、约花 X 万 token」这种 Fox 能感知的量（token 放括号里），并补一句「具体花多少钱以你服务商的账单为准」。以后 Fox 给了单价再加「约 ¥」。
3. **「不要了」「你常做的事」保持现有行为，只把文案写清楚**（审读员的选项 ①）。
4. **有行为错误的几条要一起修，不只是改字**：第 8 条（导出只写前 50 / 200 个）、第 9 条（「尚未同步」永远显示）、第 10 条（地图页的合并按钮）、第 14 条（旧入口）、第 37 条（报错被翻成「这个功能还没接上」）、第 39 条（「约整理了 513 个」是除出来的估计）、第 1 条里收集页那个永远是 0 的「已整理」页签。

## 整体判断（审读员原话）

新做的五个页面（今日、资料库、找方案、收集、发现）大体是人话，但设置、⚡ 菜单、🔔 里的「仪表盘」、⌘K 命令面板、欢迎引导还停在上一代界面的词汇里。最大的三个系统性问题：
1. 同一个东西多个名字，同一个词在不同页指不同东西。仓库 / 工具 / 项目 / 收藏 / Stars；整理 / 解析 / 摘要 / 理解卡；参考包 / 任务交接 / 交接单。「收集」和「收藏」只差一个字，意思完全不同。「已整理」在资料库里是「AI 写好了说明」，在收集页里是个永远为 0 的内部状态。
2. 开发话没翻译，尤其是钱。花钱只用 token 表达，没有一处写人民币。设置页整页是 Chat Completions / Base URL / 向量 / Gist。连 AI 写的中文说明本身都是 Agent / DAG / WAF，因为生成说明的提示词从没要求「写给不懂技术的人」。
3. 说的和做的对不上，集中在会花钱、会写库、会外发的按钮上（「尚未同步」每次启动都显示；「导出资料库」实际只导前 50 / 200 个；「标签网络」花钱却没有页面看得到结果；地图页的按钮会直接合并分类；Gist 备份其实是上传到 GitHub；「复制给 Codex」粘出去会让 Codex 直接装软件）。
