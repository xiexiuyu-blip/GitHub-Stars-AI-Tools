轮到你的

  1. 看一眼顺序

    建议先让助手能查你的收藏（小、不花 App 额度，搜索一好就能用），再做问答。想先做问答，把阶段 2 和 3 对调就行，两条线互不挡。

  2. 定问答的额度

    建议问答用独立的每日额度，起步 10 万 token，约够问 10–15 个问题（预估，真跑后校准）。整理把额度用光了，问答不会跟着死；反过来也一样。开关你自己点。

  3. 说「开始」

    你说了，我才写第一批卡、派 Codex。现在什么都没动，也没花额度。

你点名要的两件事，具体怎么做

都建在同一个检索核心上，所以先做阶段 1。

让 AI 助手自己来取 不花 App 额度

  1. Codex / Claude Code
  2. MCP 转接头
  3. App（只在你这台 Mac 上）
  4. 你的库
  • 只有 App 读写你的库。助手只能通过 App 取资料，碰不到数据库文件。
  • 默认关。打开后先只读，每次调用都记下来，设置里能看。
  • 取回的内容都标「不可信」，README 摘录限长、一次最多 20 条；你的笔记默认不给助手。
  • 配置是「复制给你」，不会替你改 Codex / Claude 的全局配置。
  • 第一版要求 App 开着，没开会提示「请先打开 Fox Stars Lab」。
  • 改库（改状态、加笔记）放到阶段 4：默认只「预演」，你在 App 里点确认才真改。

问你的收藏 花独立额度

  1. 你问
  2. 本机检索（免费）
  3. AI 答一次
  4. 校验出处
  5. 答案 + 出处
  • 答案必须带出处。出处不在检索结果里的一律丢掉；找不到就直说，不编造收藏里没有的项目。
  • 资料里夹带的「指令」一律不执行（整理说明卡、找方案用的是同一套做法）。
  • 一次回答 ≤ 300 字，网址不会自动打开；对话只存本机，不进同步。
  • 额度为 0、用完或没配 AI 服务时，仍给本地检索结果和命中原因，并有「复制给 Codex / Claude 问」。
  • 每问约 5–8 千 token 输入 + 最多 800 输出，和整理一张卡同量级（预估，真跑后校准）。
  • 入口：资料库「问问我的收藏」、⌘K 问模式、详情页「问问它」；导航仍是 5 项，不加新页。

发现

新版说明
每个项目一张：一句话、三句话讲清是什么、能做什么、我想解决什么、用之前要注意什么。场景标签都带原话出处。项目说明（README）变了会自动重新整理。
自动整理
「现在整理」是你手动点、立刻开始；「每天自动整理」是后台只处理新增和变化的。额度用完不会锁死，花钱前必须你自己点确认。
